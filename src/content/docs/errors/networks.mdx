Each network has its own rules for text, files and settings. Capybaroar checks a post against them before it's scheduled, and shows the first problem as `<channel>: <reason>`. A few messages only come back from the network when the post goes out. This page collects them all, network by network. Each network's own page has the same table and more about what it can post.

## Messages from any network

| Message | What it means | How to fix it |
| - | - | - |
| `Reconnect <channel>` | The channel was signed out when the post's time came | Reconnect it in **Channels**, then schedule the post again |
| `<what>: <the network's own message>` | The network turned the post down and said why. The first part names the step, like `Facebook post` or `Instagram media`. | Read the network's words after the colon. Most mean a permission was removed or a file can't be read. Reconnect, or change the file. |
| `... (retrying)` | A hiccup on the network's side. Capybaroar tries again by itself. | Nothing. It tries up to 6 times over about 5 hours. |
| `Media is still processing; will retry` | The network is still reading a video | Nothing. Capybaroar checks again. |
| `Capybaroar didn't keep this post's id` | An older post can't be changed or deleted from here | Change or delete it on the network |
| `the X app isn't attached to a Project in the X developer portal` | X refused Capybaroar's app (check) | Contact Capybaroar support |


## Instagram

More on the [Instagram page](/channels/instagram/).

| Message | What to do |
| - | - |
| `Instagram needs a picture or video` | Add a picture or video. Instagram doesn't take text-only posts. |
| `An Instagram Reel is one video` | Remove extra files, or set the format back to Post. |
| `An Instagram Story is one picture or video` | Keep one file for a Story. |
| `Instagram takes up to 10 files` | Remove files until there are 10 or fewer. |
| `No Instagram professional account is linked to your Facebook Pages` | Switch the account to business or creator in the Instagram app, link it to a Facebook Page, then connect again. |
| `Media processing failed: …` | Instagram couldn't read the file. Try another picture or video, or a smaller one. |

## TikTok

More on the [TikTok page](/channels/tiktok/).

| Message | What to do |
| - | - |
| `TikTok takes one video, or pictures only` | Use one video on its own, or only pictures. |
| `TikTok photo posts take JPG or WebP pictures` | Save the picture as JPG or WebP and add it again. |

| `TikTok needs one video, or 1 to 35 pictures` | Add a video or pictures. |
| `TikTok pictures must be under 20 MB` | Use smaller pictures. |
| `TikTok photo titles are up to 90 characters` | Shorten the Photo title. |
| `TikTok captions are up to 2,200 characters` | Shorten the text. |

TikTok also sends these when a post goes out:

| Message | How to fix it |
| - | - |
| `Until TikTok approves Capybaroar, set the TikTok account to private and post as Only me` | Make the account private in TikTok and pick **Only me** (check) |
| `TikTok's daily post limit for this account is reached. Try again tomorrow` | Move the post to tomorrow |
| `TikTok's daily limit for apps like Capybaroar is reached. Try again later` | Schedule it again later |
| `TikTok needs the media website verified first` | Contact Capybaroar support (check) |
| `A picture is too big for TikTok. Use pictures up to 1080 pixels on the long side.` | Resize the pictures, or crop them in Media |

<Aside type="note">
Character counts follow what people see, so an emoji counts as one. X counts some links and scripts differently, so a post right at 280 can still be turned down by X.
