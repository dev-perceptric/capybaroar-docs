Returns the connected channels the key's person can use. Call this before you write posts: it gives each channel's id, its character limit, and the settings its network takes, with the ones that are required.

```http
GET https://app.capybaroar.com/api/v1/channels?brand_id={brand_id}
```

## Parameters

| Name | In | Type | Required | Description |
| - | - | - | - | - |
| `brand_id` | query | string | No | Only this brand's channels. Leave it out for every brand you can use. |


| Field | Type | Description |
| - | - | - |
| `id` | string | The channel's id, for `channel_ids` on a post |
| `network` | string | One of `linkedin`, `linkedin-page`, `facebook`, `instagram`, `threads`, `tiktok`, `youtube`, `x`, `pinterest`, `bluesky`, `mastodon`, `telegram`, `discord`, `wordpress` |
| `network_name` | string | The network's name, like `LinkedIn Page` |
| `name` | string | The account's name on the network |
| `username` | string or null | The handle, when the network has one |
| `status` | string | `active`, or `reconnect` when the channel lost its sign-in. Posts to a `reconnect` channel are refused until it's reconnected. |
| `brand_id` | string or null | The brand the channel belongs to |
| `character_limit` | number | The most characters one post can have on this network |
| `needs_media` | boolean | `true` when every post needs a picture or video (Instagram, TikTok, YouTube, Pinterest) |
| `thread` | boolean | `true` when a post's `thread` goes out as replies (X, Threads, Bluesky, Mastodon) |
| `settings` | list | The network's own settings. See below. |

## Settings

Each setting has a `key` to send under `settings` on a post, a `label` as the app shows it, and a `kind`:

| Kind | What to send |
| - | - |
| `text` | A string |
| `textarea` | A string, line breaks allowed |
| `select` | One of `options` |
| `tags` | Words split by commas, like `"launch, design"` |
| `cover` | A picture's id from [`GET /media`](/api-reference/media/) |

`required: true` means a post to this channel is refused without it, like a YouTube `title`. `only_when` means the setting is used only when another setting has that value, like an Instagram Reel cover. Settings you leave out use the network's default, such as `format: "post"` on Instagram. Each [channel page](/channels/) lists every setting and its default.

<Aside type="note">
Character limits are counted the way people see letters, so an emoji counts as one. Networks that count differently, like X with links, may still turn down a post near the limit.
</Aside>

## Errors

| Status | Message | When |
| - | - | - |
| 400 | `brand_id must be an id from this API` | `brand_id` isn't an id |
| 404 | `Brand not found` | The key's person can't use that brand |
