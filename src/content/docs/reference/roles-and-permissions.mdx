Everyone in a workspace has one of four roles. This page shows what each role can do, area by area. The app checks the role on every action, and the API and MCP server check it the same way.

| Role | In short | Takes a seat |
| - | - | - |
| **Owner** | Made the workspace. Can do everything, including deleting it. | Yes |
| **Admin** | Runs the workspace: settings, billing, team, brands, keys and webhooks. Sees every brand. | Yes |
| **Editor** | Writes, schedules and answers for the brands they're given | Yes |
| **Client** | Sees the calendar for their brands and approves or rejects posts | No |

Clients need a plan with approvals: Pro or Agency.

## Brands

Owners and admins always see every brand. Editors and clients see only the brands picked for them when they were invited, or **All brands**. Everything below is limited to those brands: posts, channels, files, feeds, Inbox items, results and reports.

## Rules about roles

- There is one owner. The owner's role can't change, and the owner can't be removed.
- Nobody can change their own role or remove themselves. To leave, use **Delete my account** in **Your account**, or ask an admin to remove you.
- Owners and admins can invite admins, editors and clients. Inviting a client needs Pro or Agency.
- Changing a client to an admin or editor needs a free seat.
- The owner of a workspace that other people use can't delete their account while they're its only owner. Delete the workspace first. A workspace where they're the only member is deleted with the account.

## Messages you may see

| Message | Why |
| - | - |
| `Only owners and admins can change this` | An editor tried a workspace setting |
| `Clients can only approve or reject posts` | A client tried to write or delete |
| `Only owners, admins and clients can approve` | An editor pressed Approve |
| `Only owners can delete the workspace` | An admin tried to delete it |
| `Only owners can change this` | An admin tried to require two-factor |
| `Only owners and admins can change the plan` | Billing, as an editor |
| `Only owners and admins can manage webhooks` | Webhooks, as an editor's key |
| `Clients can't connect channels` | A client opened a connect link |
| `You can't post to this brand` | The brand isn't one of yours |
| `The owner's role can't change` | Someone tried to change the owner |
| `You can't change your own role` | Ask another admin |
| `Approvals come with Pro and Agency. Upgrade to use them.` | Inviting a client on Free or Creator |

<Aside type="note">
Public review links let someone approve or reject without an account. Anyone with the link can, so share it only with the right person. See [Approvals](/workspace/approvals/).
</Aside>
