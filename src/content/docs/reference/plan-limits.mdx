Prices are in US dollars. A year costs the same as ten months. Taxes may apply (check).

### How each limit counts

- **Seats** count owners, admins, editors, and open invites for those roles. Clients who only approve posts don't take a seat.
- **Brands** count every brand in the workspace. Every workspace keeps at least one.
- **Channels** count every connected account. Each Facebook Page, LinkedIn Page or other account is one.
- **Scheduled posts** count posts that are scheduled or went out with a time in this calendar month, in UTC. Drafts don't count. One post to five channels counts once.
- **AI credits** refill every month on the day your subscription started. Bought credits last 12 months.

## The free trial

A new workspace gets 14 days of Pro: 5 seats, 5 brands, 30 channels, approvals, reports and 200 AI credits. After 14 days without a paid plan, it moves to Free's limits. Nothing is deleted, but you can't add more than Free allows until you upgrade.

## Posts and files

| What | Limit |
| - | - |
| Channels on one post | 30 (through the API); one brand's channels |
| Files on one post | 20 through the API. Each network has its own count. |
| Thread | 25 posts: the first and 24 replies |
| Picture or video file | 250 MB |
| PDF | 100 MB, LinkedIn only |
| Queue lookahead | 8 weeks |
| Evergreen repeats | Every 1, 2, 4, 8, 12 or 26 weeks |
| Campaign and channel group names | 60 characters |
| Brand names | 60 characters |
| Brand voice in the brand kit | 1,500 characters |

Each network's character and file limits are in [Compare every network](/channels/).

## Bulk upload and feeds

| What | Limit |
| - | - |
| Rows in one CSV file | 500 |
| CSV file size | About 900 KB |
| RSS feed file | 2 MB |
| How often a feed is read | Every 30 minutes |
| New items turned into posts per read | 3 |
| Feed post template | 1,000 characters |

On Free, a bulk upload checks the month's post limit before it starts. A file that would go over it is refused with `Your plan allows 30 scheduled posts a month and <n> are left. Upgrade to schedule more, or save these as drafts.`

## Sign-in and security

| What | Limit |
| - | - |
| Sign-in tries for one email | 10 in 15 minutes |
| Sign-in tries from one network address | 30 in 15 minutes |
| New accounts from one network address | 10 an hour |
| Sign-up tries for one email | 5 an hour |
| Password reset emails | 3 an hour for one email |
| Sign-in links | 5 an hour for one email |
| Codes from an email | 5 tries in 10 minutes |
| Two-factor codes | 5 tries in 10 minutes |

Past a limit, the message says how long to wait, like `Try again in 12 minutes.`
